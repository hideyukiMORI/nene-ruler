## 2. 最初にやること: 施主の Windows で設定モーダルを試す

`C:\Users\Public\nene-ruler-dev.exe`（PR #63 の `4113dbb` でビルド・2026-10-18 01:28）を施主がダブルクリックで起動する。

1. ギアでモーダルが枠の右に開く（右に入らなければ左）
2. 色見本・ピッカー（押したまま引く）で枠の色がすぐ変わる
3. `#RRGGBB` の欄を押すと焦点が来て、打った文字が入る。Enter で色が変わる
4. Dark / Light が切り替わる

結果は gate-proofs 第 37.3 節に表で足す（枠の 6 項目は第 36.2 節に記録済み）。崩れたものは Issue にして直す。

## 4. 作りの要点（Windows 版）

| 何が | どこ |
| --- | --- |
| 枠の窓は `WS_EX_LAYERED` の popup ＋ `WS_THICKFRAME`。Direct2D の DC 描画先を 32 bit の DIB に結び、`UpdateLayeredWindow`（`ULW_ALPHA`）で出す。当たり判定はアルファ 1/255 の下塗り（ADR 0008 と同じ考え） | `ui-win32/src/layered_bitmap.rs`・`pen.rs`・`frame_painter.rs` |
| `WM_NCCALCSIZE` は常に 0（返さないと最初の幅が 384 px になる）。`WM_NCHITTEST` は core の当たり判定を `NonClientHit` に写して返す（Linux でテストできる） | `frame_window.rs`・`non_client_hit.rs` |
| 枠とモーダルは 1 つの `RefCell<WindowsApp>` を `GWLP_USERDATA` で共有。窓の手続きは `try_borrow_mut`、借りている間に入れ子で届いたメッセージは既定の手続きへ。窓を閉じるのは `WM_CLOSE` を投げて後で | `frame_window.rs`・`windows_app.rs`・gate-proofs 37.2 |
| 文字は Segoe UI。描画先の dpi は 96 に固定し、拡大は core の `Scale` で掛ける。プロセスは per-monitor v2 の dpi 対応 | `pen.rs`・`frame_window.rs` |
| 設定は `%APPDATA%\nene-ruler\settings.v1.txt`（Linux と同じ形式・同じクレート） | `settings-file` |
| 最前面の切り替えは `SetWindowPos(HWND_TOPMOST / HWND_NOTOPMOST)` | `windows_app.rs` の `set_layer` |

## 5. 地雷

- **WSL で作った exe を `/mnt/c/Users/Public/` へ置いて試す。** リンカの `corrupt .drectve at end of def file` の警告は無害
- **PowerShell は dpi 非対応。** `PostMessage` で送る座標は施主の拡大率（125%）で直されるので、物理座標を 1.25 で割って送る。`FindWindow` のクラス名だけで探すときは窓の名前に `[NullString]::Value`（`$null` は空文字になる）。枠のクラスは `NeNeRulerFrame`、モーダルは `NeNeRulerSettings`
- **試験で変えた環境はその場で戻す。** `Xft.dpi` を残すと Linux 版が 2x で描かれ、「目盛が何倍にもなった」に見える（10-18 に施主を惑わせた）。Xvfb は `-noreset` で起動しないと `xrdb` の値が消える
- **プロセスは PID で止める。** `pkill -f nene-ruler` は施主が起動したものまで止める
- `..Default::default()` は CNF-001 が拒む。Win32 の構造体は `WNDCLASSW::default()` のように型名で書く
- `windows` クレートに無い定数（`WM_MOUSELEAVE` など）は、機能フラグを足さずにその場で定数にしている
