## 5. 地雷

- **check.yml は PR を開いただけでは走らない。** draft で開いて `gh pr ready` で走る
- **squash の件名は `gh pr merge --subject` で `(#Issue)` 1 つに揃える。** 既定だと `(#Issue) (#PR)` になる（#95・#97 で当たった）
- **Store 版を試すときは、起動した exe のパスを確かめる。** 施主の機械には MSI 版も入っていて、スタートメニューからは区別できない。Store 版は `explorer.exe 'shell:AppsFolder\HideyukiMori.NeNeRuler_3sft4ch5kzywy!NeNeRuler'` で起動できる
- Windows PowerShell 5.1 で動かす `.ps1` は BOM 付きにする
- 画面を使う前は、施主の明示の合図を待つ
