## 5. 地雷

- **check.yml は PR を開いただけでは走らない。** draft で開いて `gh pr ready` で走る。`--undo` と `ready` の間に数秒置き、`gh run list --branch` で head の sha の run があるか見る
- **main の ruleset は未設定。** 失敗した check があっても merge できてしまう（#109 で当たった）。merge の前に `gh pr checks` を自分で見る
- **squash の件名は `gh pr merge --squash --subject` で `(#Issue)` 1 つに揃える。** 今日の 5 本は `(#Issue) (#PR)` のまま
- **積んだ枝を main に載せ替えるときの `git rebase --onto main <upstream>` の upstream は、rebase 前の親の sha。** rebase 済みの枝の名を指すと古いコミットまで載ろうとして衝突する（#105 で当たった）
- **1.0.0 のパーサは `unit = physical_px` を知らない。** 新旧を同じ `%APPDATA%` で行き来すると 1.0.0 が既定に戻る（壊れない）
- **Store 版を試すときは、起動した exe のパスを確かめる。** Store 版は `explorer.exe 'shell:AppsFolder\HideyukiMori.NeNeRuler_3sft4ch5kzywy!NeNeRuler'` で起動できる
- 実行中の exe は `cp` で上書きできない（Windows のロック）。別のフォルダに置く
- Windows PowerShell 5.1 で動かす `.ps1` は BOM 付きにする
- 画面を使う前は、施主の明示の合図を待つ
