# ADR 0023 — アイコンの絵を core に移し、唯一の build.rs で Windows の exe に埋める

- 状態: 受理
- 日付: 2026-10-18
- Issue: #68
- 影響する規則: ARC-001 / ARC-007 / RS-010 / RS-015 / CNF-008 / CNF-012。ADR 0020 の決定（cairo で描く）と 5 を改める

## 文脈

ADR 0020 はアイコンを `ui-x11` の cairo で描き、`_NET_WM_ICON` に付けた。5 は「Windows 版・Store の配布物のアイコンは同じ絵から出す」とした。

Windows 版（ADR 0021）にはアイコンが無く、タスクバー・Alt+Tab・エクスプローラーで既定の絵になる。施主は推しの「exe に `.ico` を埋める」を選んだ（2026-10-18）。エクスプローラーの exe の絵は、exe の資源にしか置けない。

資源を exe に入れるには、ビルドの時に `.ico` を作り、資源のオブジェクトにしてリンクする処理が要る。RS-010 は「`build.rs` を書かない」（ビルド時にコードを生成しない）とし、CNF-008 がそれを、CNF-012 がファイルとコマンドを拒んでいる。施主は、規約を緩めて 1 ファイルだけ例外にする案を選んだ（2026-10-18）。

## 決定

**絵の正本と画素への塗りを core の `AppIcon` に、`.ico` の書き出しを core の `icon_file` に置く。`crates/app/build.rs` を唯一のビルドスクリプトとして許し、Windows のターゲットでだけ `.ico` と `.rc` を `OUT_DIR` に書いて `windres` で exe に埋める。**

1. `AppIcon` は 128 の格子の整数の形を、1 画素 8 × 8 の標本で塗る。浮動小数を使わないので、ビルドの機械でも実行の機械でも同じ画素になる。形と色は ADR 0020 のまま
2. X11 の `_NET_WM_ICON`（16〜128 の 6 枚）も `AppIcon` から作る。cairo のアイコンの絵は消す（絵の経路を 1 本にする・ARC-001）
3. `.ico` は 16 / 20 / 24 / 32 / 40 / 48 / 64 / 256 の 8 枚を、32 ビットの BMP と AND マスクで入れる（PNG は圧縮の実装が要るので使わない）
4. `build.rs` は資源（アイコン）を作るだけで、Rust のコードを生成しない。Windows 以外のターゲットでは何もしない。Windows は gnu のターゲット（`{arch}-w64-mingw32-windres`、`WINDRES` で差し替え）だけ。MSVC は明示的に失敗させる
5. 資源番号は 1。`ui-win32` は窓の類に、資源のアイコンを系統の大・小の大きさで読む
6. 例外は `crates/app/build.rs` の 1 つだけ。CNF-008 はそれ以外の `build.rs` とマニフェストの `build = ` を今まで通り拒み、CNF-012 はそのファイルだけファイル・環境・コマンドを許す。build-dependency は内部の core だけ

## 強制

- **active**: CNF-008 / CNF-012 の正例・反例（例外のファイルは通り、同じクレートの別の置き場・別のクレートの `build.rs` と `main.rs` のファイル操作は落ちる）。`make prove`
- **active**: core の単体テスト（地・2 つの鉤括弧・角の半端なアルファ・16 px で腕が残る・決定性・`.ico` の頭と項目と画像の並び）、ui-x11 の `_NET_WM_ICON` の長さと並び
- **planned**: 施主の Windows でのエクスプローラー・タスクバー・Alt+Tab の見え（QLT-013）

## 結果

- 絵の正本が core の 1 か所になり、X11 と Windows が同じ画素を使う
- exe が約 330 KiB 大きくなる（256 px の BMP）
- Windows の exe を作るには mingw-w64 の `windres` が要る（リンカと同じ道具の組。`make doctor` で確かめる）
- ビルドスクリプトが 1 つ入る。ビルドの時に動くコードが増えるので、例外の範囲は検査で固定する

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 実行時にだけアイコンを作って窓に付ける（`CreateIconIndirect`） | 規約は緩めずに済むが、エクスプローラーの exe の絵が既定のままになる。施主は埋める方を選んだ |
| `.ico` をリポジトリに置き、Makefile で `windres` してリンクの引数で渡す | 絵の正本が 2 つになる（ADR 0020 の却下理由と同じ）。`cargo build` だけでは絵が入らない |
| `embed-resource` / `winresource` クレート | 依存が増える（ARC-013）。`windres` を呼ぶだけなら自前で数十行 |
| `.ico` を PNG で入れる | 小さくなるが、deflate と CRC の実装が要る |
