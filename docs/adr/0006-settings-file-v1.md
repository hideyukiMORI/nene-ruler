# ADR 0006 — 設定は版付きの `key = value` テキストで保存し、読めない版は既定値へ落とさない

- 状態: 受理（`unit` の鍵は置換 → [0012](0012-px-only-and-no-layer-notice.md) → [0027](0027-logical-pixel-unit.md)）
- 日付: 2026-10-16
- Issue: #6
- 影響する規則: ARC-003 / ARC-007 / ARC-008 / ARC-009 / ARC-010 / ARC-013 / RS-015。仕様 FR-012 / FR-014

## 文脈

保存する値は 4 つで、どれも閉じた集合か `#RRGGBB` である（`RulerSettings`: インク色・モーダルの見え・単位・重なり順）。
FR-012 は置き場を `$XDG_CONFIG_HOME/nene-ruler/settings.v1.txt`（未設定なら `~/.config`）と決めている。
ARC-009 は、保存形式が明示的な版を持ち、読めない版を既定値へ黙って落とさず、直列化の型を core の型と分けることを求める。
ARC-013 は依存の追加に ADR を求め、中核は依存 0 である。

## 決定

**設定は 1 行 1 項目の `key = value` のテキストで保存する。1 行目は `version = 1`。直列化の型と読み書きは adapters-x11 に閉じ、依存は足さない。**

1. **形式（版 1）**:

   ```text
   version = 1
   ink = #E53935
   modal_theme = dark
   unit = px
   layer = always_on_top
   ```

   `key = value`。空行と `#` で始まる行は無視する。鍵の順は問わないが、書くときは上の順で書く（RS-016）。
   値はすべて閉じた語（`dark` / `light`、`px` / `mm` / `in`、`always_on_top` / `normal`）か `#RRGGBB`
2. **版**: 最初の `version` 行が `1` でなければ `UnknownVersion` として読まない。`version` 行が無ければ `Malformed`。鍵が足りない・値が読めないのも `Malformed`
3. **無いことと読めないことを分ける**: ファイルが無ければ `Ok(None)`（初回起動）、読めなければ `Err(SettingsStoreFailure)`。application は後者を既定値で起動したうえで利用者に示す（FR-014）
4. **書き込み**: 親ディレクトリを作り、同じディレクトリの一時ファイルへ書いてから `rename` で置き換える。途中で落ちても半端なファイルが残らない
5. **置き場の解決**: `XDG_CONFIG_HOME` が空でなければそれ、無ければ `HOME/.config`。どちらも無ければ `NoConfigDirectory`。環境変数を読むのは adapters-x11 だけ（ARC-007 / CNF-012）
6. **直列化の型**: `SettingsFileV1`（adapters-x11）。`RulerSettings` との変換は双方向の純関数で、ファイル無しで単体テストする（ARC-008: 境界で一度だけ検証し、core の型へ写す）

## 強制

- **active**: 環境とファイルに触れる場所が adapters-x11 だけであること（CNF-012）。中核が `std::fs` に到達できないこと（CNF-007 の `#![no_std]`）
- **active**: 直列化の往復・壊れた入力・未知の版の単体テスト（`cargo test -p nene-ruler-adapters-x11`）
- **planned**: ARC-009 そのもの（版の規律）はレビュー事項のまま。版 2 を作るときに移行の規則と回帰テストを足す

## 結果

得られるもの:

- 依存 0 のまま。人が読めて手で直せる（`#RRGGBB` の直接編集も効く）
- 版が最初の行にあるので、将来の版 2 は 1 行読めば分岐できる
- 「無い」「読めない」「書けない」が型で分かれ、UI がそのまま示せる

失うもの・残る穴:

- 鍵の綴りを間違えたファイルは `Malformed` で丸ごと拒む。部分的に読む救済はしない（黙って落とさないため）
- 同時に 2 つ起動して両方が書くと、後に書いたほうが勝つ。排他はしない（1 つしか起動しない道具）
- 書けない失敗（権限・ディスク）は、保存のたびに示すが、再試行はしない

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| TOML / JSON のクレート | 4 項目のために依存とライセンスが増える（ARC-013）。閉じた語しか無いので自前の 1 行 1 項目で足りる |
| バイナリ・`bincode` | 人が読めず、手で直せない。版の分岐も頭を読む自前の処理になる |
| `serde` の derive | 中核が依存 0 でなくなるか、adapters で型を二重に持つ。4 項目では手書きのほうが短い |
| 読めない行だけ飛ばして残りを使う | 「既定値へ黙って落とす」の部分版。ARC-009 に反する |
| 窓の位置と大きさも保存する | 仕様に無い。WM が覚える環境もあり、画面構成が変わると画面外に出る |
