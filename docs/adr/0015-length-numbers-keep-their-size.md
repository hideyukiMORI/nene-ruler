# ADR 0015 — 幅と高さの数字も倍率に関わらず 11 px で描く

- 状態: 置換 → [0028](0028-text-in-logical-pixels-and-ticks-follow-the-unit.md)（字の大きさは論理画素 11 で、比で物理画素にする・2026-10-20）
- 日付: 2026-10-17
- Issue: #38
- 影響する規則: FR-004 / FR-007 / FR-016。ADR 0011 の決定 2 のうち「幅と高さの数字」を置き換える（主目盛の数字は ADR 0013）

## 文脈

ADR 0013 で主目盛の数字を 9 px に固定した後、施主は WSLg で 2x の定規を見て「目盛の数字はいい感じ。width, height の数値ももっと小さくていい」とした（2026-10-17）。2x では `400 px` が 22 px になっていた。

## 決定

**幅と高さの数字の字（11 px）と、その当たり判定の見積り（字の高さ 11 px・1 文字 7 px）には倍率を掛けない。** 目盛の長さ・字との隙間・鉤括弧・ギア・通知・帯は ADR 0011 のまま倍率を掛ける。

## 強制

- **active**: core の単体テスト（2x の横の数字のベースライン (208, 61) と当たり判定 (187, 50, 42, 15)。縦の数字と通知が左辺の数字と重ならない）
- **planned**: 施主の目視（QLT-013）

## 結果

- 2x の枠では、倍率が掛かるのは鉤括弧・ギア・目盛の長さ・帯・通知だけになる。字は通知を除いて 1x と同じ
- 数字の当たり判定も 1x の大きさなので、4K では押せる範囲が小さい（42 × 15 px）

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 当たり判定だけ 2x の大きさのまま残す | 描いた字より大きな矩形が「見えないが触れる」所になり、WSLg ではアルファ 1 の帯として線の近くまで広がる（ADR 0008） |
