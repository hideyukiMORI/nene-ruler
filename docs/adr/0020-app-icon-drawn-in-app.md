# ADR 0020 — アプリのアイコンは 2 つの鉤括弧で、画像ファイルを同梱せずその場で描く

- 状態: 受理（描き方と Windows の配布物は置換 → [0023](0023-icon-embedded-by-the-only-build-script.md)）
- 日付: 2026-10-17
- Issue: #58
- 影響する規則: ARC-001 / ARC-013。ADR 0002（cairo の ImageSurface）

## 文脈

窓にアイコンが無く、タスクバーや Alt+Tab で既定の絵になっていた。2026-10-17、施主がデザインのカンバス（案 A 鉤括弧・B 鉤括弧＋目盛・C 差し金・ファミリーの並び）から **A** を選んだ。

NeNe Clock のアイコンは、暗い角丸の地（`#1A1917`・格子 128・角 26）に生成り（`#F5F2EB`）と差し色の 2 要素だけで、画像を同梱せず要る大きさをその場で描いている（16 px で残る形・絵の正本は 1 つ）。B と C の目盛は 16〜24 px で潰れた。

## 決定

**アイコンは、暗い角丸の地に、左上の生成りの鉤括弧と右下の赤（`#E53935`）の鉤括弧。`crates/ui-x11/src/app_icon.rs` が cairo で 16 / 24 / 32 / 48 / 64 / 128 px を描き、非 premultiplied の ARGB にして `_NET_WM_ICON` として枠とモーダルの窓に付ける。**

1. 鉤括弧は腕の長さ 44・太さ 14（格子 128）。16 px で太さ 1.75 px 残る
2. 右下（掴んで伸ばす方）だけ色を変える。NeNe Clock の「動く方の点だけ色を変える」と同じ
3. 差し色は既定のインク色に固定する。利用者がインク色を変えてもアイコンは変わらない（製品の印）
4. 256 px は入れない。`_NET_WM_ICON` が 1 つの X の要求の上限（既定 256 KiB）に近づく
5. Windows 版・Microsoft Store の配布物のアイコンは、Windows 版を作るときに同じ絵から出す

## 強制

- **active**: 画素テスト（128 px の角が透明・地・左上の腕が生成り・右下の腕が赤）、`_NET_WM_ICON` の長さと並び、premultiplied から戻す計算
- **active**: Xvfb で `xprop _NET_WM_ICON` に 6 つの大きさが出る（gate-proofs 第 35 節）
- **planned**: WSLg のタスクバーでの見え（施主の目視）

## 結果

- 画像ファイルも、その書き出しの手順も要らない。どの大きさも同じ式から出る
- アイコンは定規の見た目（2 つの鉤括弧）とそのまま対応する

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| B（鉤括弧＋目盛） | 目盛の細い線が 16〜24 px で潰れる |
| C（差し金） | 目盛の切り込みが 16 px で見えない。鉤括弧（この定規の操作の印）と対応しない |
| PNG を同梱する | 大きさごとの書き出しと同梱が要り、絵の正本が 2 つになる。依存（PNG の読み込み）も増える |
| 差し色を利用者のインク色に追従させる | タスクバーのアイコンが人ごとに変わり、製品の印にならない |
